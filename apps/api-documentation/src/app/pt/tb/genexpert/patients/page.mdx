# TB GeneXpert - Pacientes

Endpoints de pesquisa ao nível do paciente para resultados de TB GeneXpert. Estes endpoints permitem pesquisar registos individuais de pacientes por nome, unidade sanitária, tipo de amostra ou tipo de resultado. Todas as respostas são paginadas e incluem dados demográficos detalhados, informações da unidade sanitária, dados do espécime e resultados completos do GeneXpert incluindo marcadores de resistência a medicamentos. {{ className: 'lead' }}

## Parâmetros comuns

<Row>
  <Col>
    Todos os endpoints de pesquisa de pacientes aceitam os seguintes parâmetros de consulta para filtragem e paginação.

    <Properties>
      <Property name="interval_dates" type="JSON array">
        Filtro de intervalo de datas como array JSON com duas datas no formato `YYYY-MM-DD`: `["2025-01-01","2025-12-31"]`. Predefinido: últimos 12 meses.
      </Property>
      <Property name="province" type="string">
        Filtro por nome da província. Seleção múltipla suportada.
      </Property>
      <Property name="district" type="string">
        Filtro por nome do distrito. Seleção múltipla suportada.
      </Property>
      <Property name="genexpert_result_type" type="string">
        Filtrar por tipo de cartucho: `"Ultra 6 Cores"` ou `"XDR 10 Cores"`.
      </Property>
      <Property name="page" type="integer">
        Número da página para paginação. Predefinido: `1`.
      </Property>
      <Property name="per_page" type="integer">
        Número de resultados por página. Predefinido: `20`.
      </Property>
    </Properties>
  </Col>
  <Col sticky>
    <CodeGroup title="Pedido com parâmetros" tag="GET" label="/tb/gx/patients/by_name/">
    ```bash {{ title: 'cURL' }}
    curl -G https://api.openldr.org.mz/tb/gx/patients/by_name/ \
      -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
      --data-urlencode 'interval_dates=["2025-01-01","2025-12-31"]' \
      --data-urlencode "first_name=Maria" \
      --data-urlencode "surname=Silva" \
      --data-urlencode "genexpert_result_type=Ultra 6 Cores" \
      --data-urlencode "page=1" \
      --data-urlencode "per_page=20"
    ```
    </CodeGroup>
  </Col>
</Row>

## Pesquisar por nome {{ tag: 'GET', label: '/tb/gx/patients/by_name/' }}

<Row>
  <Col>
    Pesquisar resultados GeneXpert de pacientes por primeiro nome e/ou apelido. Retorna resultados paginados com detalhes completos do paciente, informações da unidade sanitária, dados do espécime e resultados de testes incluindo marcadores de resistência a medicamentos.

    <Properties>
      <Property name="first_name" type="string">
        Primeiro nome do paciente para pesquisar. Correspondência parcial suportada.

      <Property name="surname" type="string">

        Número da página actual.
      </Property>
      <Property name="per_page" type="integer">
        Número de resultados por página.
      </Property>
      <Property name="total_count" type="integer">
        Total de registos correspondentes.
      </Property>
      <Property name="total_pages" type="integer">
