## Testes de Cultura

Teste de cultura micobacteriana utilizando meios líquidos (MGIT) e sólidos (Lowenstein-Jensen) para diagnóstico definitivo de TB. A cultura continua a ser o padrão de referência para o diagnóstico de TB e é essencial para testes de susceptibilidade a medicamentos.

## Testes de Sensibilidade a Medicamentos

Testes de susceptibilidade a medicamentos (TSA) de primeira e segunda linha para orientar o tratamento de TB resistente a medicamentos. Inclui testes para isoniazida, rifampicina, etambutol, pirazinamida, fluoroquinolonas e agentes injectáveis.
