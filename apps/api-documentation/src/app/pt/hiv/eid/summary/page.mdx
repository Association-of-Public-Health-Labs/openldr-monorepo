# HIV DPI - Resumo

Endpoints de resumo e painel para analytics de Diagnóstico Precoce Infantil (DPI/EID) de HIV. Estes endpoints fornecem indicadores agregados, taxas de positividade, tempos de resposta e dados ao nível de equipamento em todas as unidades sanitárias. {{ className: 'lead' }}

## Parâmetros comuns

<Row>
  <Col>
    A maioria dos endpoints de resumo aceita um conjunto comum de parâmetros de consulta para filtragem de dados por intervalo de datas, localização geográfica, atributos da unidade sanitária e tipo de laboratório.

    <Properties>
      <Property name="interval_dates" type="JSON array">
        Filtro de intervalo de datas como um array JSON com duas datas no formato `YYYY-MM-DD`: `["2025-01-01","2025-12-31"]`. Por padrão, retorna os últimos 12 meses caso não seja fornecido.
      </Property>
      <Property name="province" type="string">
        Filtrar por nome da província. Suporta seleção múltipla passando o parâmetro várias vezes.
      </Property>
      <Property name="district" type="string">
        Filtrar por nome do distrito. Suporta seleção múltipla passando o parâmetro várias vezes.
      </Property>
      <Property name="health_facility" type="string">
        Filtrar por nome de uma unidade sanitária específica.
      </Property>
      <Property name="facility_type" type="string">
        Nível de agrupamento para resultados agregados. Valores aceites: `"province"`, `"district"`, `"health_facility"`.
      </Property>
      <Property name="disaggregation" type="string">
        Activar ou desactivar a desagregação de dados. Valores aceites: `"True"` ou `"False"`.
      </Property>
      <Property name="lab_type" type="string">
        Filtrar por tipo de laboratório. Valores aceites: `"conventional"`, `"poc"`, `"all"`.
      </Property>
    </Properties>
  </Col>
  <Col sticky>
    <CodeGroup title="Requisição com parâmetros" tag="GET" label="/hiv/eid/summary/indicators/">
    ```bash {{ title: 'cURL' }}
    curl -G https://dev.openldr.org.mz/hiv/eid/summary/indicators/ \
      -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
      --data-urlencode 'interval_dates=["2025-01-01","2025-12-31"]' \
      --data-urlencode "province=Maputo Cidade" \
      --data-urlencode "district=KaMpfumo" \
      --data-urlencode "facility_type=district" \
      --data-urlencode "disaggregation=True" \
      --data-urlencode "lab_type=all"
    ```
    </CodeGroup>
  </Col>

## TAT {{ tag: 'GET', label: '/hiv/eid/summary/tat/' }}

<Row>
  <Col>
    Retorna um array de médias mensais de tempo de resposta (TAT) desagregadas por cada etapa do fluxo de processamento da amostra, desde a colheita até à validação.

    <Properties>
      <Property name="year" type="integer">
        O ano do registo.
      </Property>
      <Property name="month" type="integer">
        O número do mês (1-12).
      </Property>
      <Property name="month_name" type="string">
        O nome do mês.
      </Property>
      <Property name="collection_receiveHub" type="float">
        Média de dias desde a colheita da amostra até à recepção no hub.
      </Property>
      <Property name="receiveHub_registrationHub" type="float">
        Média de dias desde a recepção no hub até ao registo no hub.
      </Property>
      <Property name="registrationHub_receiveLab" type="float">
        Média de dias desde o registo no hub até à recepção no laboratório.
      </Property>
      <Property name="receiveLab_registrationLab" type="float">
        Média de dias desde a recepção no laboratório até ao registo no laboratório.
      </Property>
      <Property name="registrationLab_analyseLab" type="float">
        Média de dias desde o registo no laboratório até à análise.
      </Property>
      <Property name="analyseLab_validationLab" type="float">
        Média de dias desde a análise até à validação do resultado.
