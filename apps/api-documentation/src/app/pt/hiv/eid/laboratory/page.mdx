# HIV DPI - Laboratório

Endpoints a nível laboratorial para análises de Diagnóstico Precoce Infantil (DPI/EID) do HIV. Estes endpoints fornecem dados de testagem agrupados por unidade de testagem, incluindo contagens de amostras, taxas de positividade, tempos de resposta, utilização de equipamentos e rotas geográficas de amostras. {{ className: 'lead' }}

## Parâmetros comuns

<Row>
  <Col>
    A maioria dos endpoints laboratoriais aceita os seguintes parâmetros de consulta para filtragem e agregação de dados. Estes parâmetros permitem restringir os resultados por intervalo de datas, localização geográfica, tipo de unidade e nível de detalhe.

    <Properties>
      <Property name="interval_dates" type="JSON array">
        Filtro de intervalo de datas como um array JSON com duas datas no formato `YYYY-MM-DD`: `["2025-01-01","2025-12-31"]`. Por padrão, considera os últimos 12 meses se não for fornecido.
      </Property>
      <Property name="province" type="string">
        Filtrar por nome da província. Suporta seleção múltipla passando o parâmetro várias vezes.
      </Property>
      <Property name="district" type="string">
        Filtrar por nome do distrito. Suporta seleção múltipla passando o parâmetro várias vezes.
      </Property>
      <Property name="health_facility" type="string">
        Filtrar por nome de uma unidade sanitária específica.
      </Property>
      <Property name="facility_type" type="string">
        Nível de agrupamento para resultados agregados. Valores aceites: `"province"`, `"district"`, `"health_facility"`.
      </Property>
      <Property name="disaggregation" type="string">
        Ativar ou desativar a desagregação dos dados. Valores aceites: `"True"` ou `"False"`.
      </Property>
      <Property name="lab_type" type="string">
        Filtrar por tipo de laboratório. Valores aceites: `"conventional"`, `"poc"`, `"all"`.
      </Property>
    </Properties>
  </Col>
  <Col sticky>
    <CodeGroup title="Requisição com parâmetros" tag="GET" label="/hiv/eid/laboratories/tested_samples/">
    ```bash {{ title: 'cURL' }}
    curl -G https://api.openldr.org.mz/hiv/eid/laboratories/tested_samples/ \
      -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
      --data-urlencode 'interval_dates=["2025-01-01","2025-12-31"]' \
      --data-urlencode "province=Maputo Cidade" \
      --data-urlencode "facility_type=district" \
      --data-urlencode "disaggregation=True" \
      --data-urlencode "lab_type=conventional"
    ```
    </CodeGroup>

## TAT {{ tag: 'GET', label: '/hiv/eid/laboratories/tat/' }}

<Row>
  <Col>
    Retorna as médias de tempo de resposta (TAT) por unidade de testagem, discriminadas por cada segmento da cadeia de transporte e processamento de amostras. Os valores representam a média de dias para cada segmento.

    <Properties>
      <Property name="testing_facility" type="string">
        O nome do laboratório de testagem.
      </Property>
      <Property name="collection_receiveHub" type="float">
        Média de dias desde a colheita da amostra até à recepção no hub.
      </Property>
      <Property name="receiveHub_registrationHub" type="float">
        Média de dias desde a recepção no hub até ao registo no hub.
      </Property>
      <Property name="registrationHub_receiveLab" type="float">
        Média de dias desde o registo no hub até à recepção no laboratório.
      </Property>

        Média de dias desde a recepção no laboratório até ao registo no laboratório.
      </Property>
      <Property name="registrationLab_analyseLab" type="float">
        Média de dias desde o registo no laboratório até à análise da amostra.

## TAT amostras {{ tag: 'GET', label: '/hiv/eid/laboratories/tat_samples/' }}

<Row>
  <Col>
    Retorna o número de amostras agrupadas por intervalos de tempo de resposta para uma determinada categoria de segmento TAT. Utilize este endpoint para compreender a distribuição dos tempos de processamento em intervalos definidos.

    Para além dos parâmetros comuns, este endpoint aceita o seguinte:

    <Properties>
      <Property name="category" type="integer">
        O segmento TAT a analisar. Valores aceites: `1` (colheita até recepção no hub), `2` (recepção no hub até registo no hub), `3` (registo no hub até recepção no laboratório), `4` (recepção no laboratório até registo no laboratório), `5` (registo no laboratório até análise), `6` (análise até validação).
      </Property>
    </Properties>

    <span className="block mt-4 font-medium">Campos da resposta:</span>

    <Properties>
      <Property name="category" type="string">
        O nome do segmento TAT a ser medido.
      </Property>
      <Property name="less_7" type="integer">
        Número de amostras processadas em menos de 7 dias.
      </Property>
      <Property name="between_7_14" type="integer">
        Número de amostras processadas entre 7 e 14 dias.
      </Property>
      <Property name="between_15_21" type="integer">
        Número de amostras processadas entre 15 e 21 dias.
      </Property>
      <Property name="greater_21" type="integer">
        Número de amostras processadas em mais de 21 dias.
      </Property>
    </Properties>
  </Col>
  <Col sticky>
    <CodeGroup title="Requisição" tag="GET" label="/hiv/eid/laboratories/tat_samples/">

    ```bash {{ title: 'cURL' }}
    curl -G https://api.openldr.org.mz/hiv/eid/laboratories/tat_samples/ \
      -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
      --data-urlencode 'interval_dates=["2025-01-01","2025-12-31"]' \
      --data-urlencode "category=1"
    ```
    </CodeGroup>

```json {{ title: 'Response' }}
    "category": "Collection to Hub Reception",
```
