# HIV DPI - Unidades Sanitarias

Endpoints a nivel de unidades sanitarias para analises de Diagnostico Precoce Infantil (DPI/EID) do HIV. Estes endpoints fornecem dados agrupados por unidade sanitaria requisitante (unidade sanitaria que enviou a amostra), incluindo contagens de amostras, positividade, desagregacao por genero, tempos de resposta, dados de rejeicao e analise por faixa etaria. {{ className: 'lead' }}

## Parametros comuns

<Row>
  <Col>
    A maioria dos endpoints de DPI a nivel de unidades sanitarias aceita um conjunto comum de parametros de consulta para filtrar resultados por intervalo de datas, geografia e nivel de agregacao.

    <Properties>
      <Property name="interval_dates" type="JSON array">
        Filtro de intervalo de datas como um array JSON com duas datas no formato `YYYY-MM-DD`: `["2025-01-01","2025-12-31"]`. Por defeito, retorna os ultimos 12 meses se nao for fornecido.
      </Property>
      <Property name="province" type="string">
        Filtrar por nome da provincia. Suporta seleccao multipla passando o parametro varias vezes.
      </Property>
      <Property name="district" type="string">
        Filtrar por nome do distrito. Suporta seleccao multipla passando o parametro varias vezes.
      </Property>
      <Property name="health_facility" type="string">
        Filtrar por nome de uma unidade sanitaria especifica.
      </Property>
      <Property name="facility_type" type="string">
        Nivel de agrupamento para resultados agregados. Valores aceites: `"province"`, `"district"`, `"health_facility"`.
      </Property>
      <Property name="disaggregation" type="string">
        Activar ou desactivar a desagregacao de dados. Valores aceites: `"True"` ou `"False"`.
      </Property>
      <Property name="lab_type" type="string">
        Filtrar por tipo de laboratorio. Valores aceites: `"conventional"`, `"poc"`, `"all"`.
      </Property>
    </Properties>
  </Col>
  <Col sticky>
    <CodeGroup title="Request with parameters" tag="GET" label="/hiv/eid/facilities/">
    ```bash {{ title: 'cURL' }}
    curl -G https://api.openldr.org.mz/hiv/eid/facilities/registered_samples/ \
      -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
      --data-urlencode 'interval_dates=["2025-01-01","2025-12-31"]' \
      --data-urlencode "province=Maputo Cidade" \
      --data-urlencode "district=KaMpfumo" \
      --data-urlencode "facility_type=health_facility" \
      --data-urlencode "disaggregation=True" \
      --data-urlencode "lab_type=conventional"
    ```
    </CodeGroup>
  </Col>
