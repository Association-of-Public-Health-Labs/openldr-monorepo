# HIV CV - Resumo

Endpoints de resumo e painel do sistema para análises de Carga Viral (CV) do HIV. Estes endpoints fornecem indicadores agregados, tendências de supressão viral, tempos de resposta e desagregações provinciais em todas as unidades. {{ className: 'lead' }}

## Parâmetros comuns

<Row>
  <Col>
    A maioria dos endpoints de resumo aceita um conjunto comum de parâmetros de consulta para filtrar dados por intervalo de datas, localização geográfica e atributos das unidades.

    <Properties>
      <Property name="interval_dates" type="JSON array">
        Filtro de intervalo de datas como um array JSON com duas datas no formato `YYYY-MM-DD`: `["2025-01-01","2025-12-31"]`. Predefinido: últimos 12 meses.
      </Property>
      <Property name="province" type="string">
        Filtro por nome da província. Seleção múltipla suportada.
      </Property>
      <Property name="district" type="string">
        Filtro por nome do distrito. Seleção múltipla suportada.
      </Property>
      <Property name="health_facility" type="string">
        Filtro por nome específico da unidade sanitária.
      </Property>
      <Property name="facility_type" type="string">
        Nível de agrupamento para resultados agregados. Valores aceites: `"province"`, `"district"`, `"health_facility"`.
      </Property>
      <Property name="disaggregation" type="string">
        Ativar ou desativar a desagregação de dados. Valores aceites: `"True"` ou `"False"`.
      </Property>
    </Properties>
  </Col>
  <Col sticky>
    <CodeGroup title="Pedido com parâmetros" tag="GET" label="/hiv/vl/summary/header_indicators/">
    ```bash {{ title: 'cURL' }}
    curl -G https://api.openldr.org.mz/hiv/vl/summary/header_indicators/ \
      -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
      --data-urlencode 'interval_dates=["2025-01-01","2025-12-31"]' \
      --data-urlencode "province=Maputo Cidade" \
      --data-urlencode "district=KaMpfumo" \
      --data-urlencode "facility_type=district" \
      --data-urlencode "disaggregation=True"
    ```
    </CodeGroup>
  </Col>
</Row>

<div className="not-prose my-16 border-t border-zinc-900/5 dark:border-white/5" />

## Indicadores do cabeçalho {{ tag: 'GET', label: '/hiv/vl/summary/header_indicators/' }}

<Row>
  <Col>
    Retorna um objeto único com os principais indicadores de CV para o período selecionado, incluindo totais de amostras registadas, testadas, suprimidas, não suprimidas e rejeitadas.

    <Properties>
      <Property name="registered" type="integer">
        Número total de amostras registadas no sistema.
      </Property>
      <Property name="tested" type="integer">
        Número total de amostras que foram testadas.
      </Property>
      <Property name="suppressed" type="integer">
        Número total de amostras com resultado de carga viral suprimida.
      </Property>
      <Property name="not_suppressed" type="integer">
        Número total de amostras com resultado de carga viral não suprimida.
      </Property>
      <Property name="rejected" type="integer">
        Número total de amostras que foram rejeitadas.
      </Property>
    </Properties>
  </Col>
  <Col sticky>
    <CodeGroup title="Pedido" tag="GET" label="/hiv/vl/summary/header_indicators/">
    ```bash {{ title: 'cURL' }}
    curl -G https://api.openldr.org.mz/hiv/vl/summary/header_indicators/ \
      -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
      --data-urlencode 'interval_dates=["2025-01-01","2025-12-31"]'
    ```

  "suppressed": 148920,

## TAT {{ tag: 'GET', label: '/hiv/vl/summary/tat/' }}

<Row>
  <Col>
    Retorna um array de médias mensais de tempo de resposta (TAT) desagregadas por cada etapa do pipeline de processamento de amostras, desde a colheita até à validação.

    <Properties>
      <Property name="year" type="integer">
        O ano do registo.
      </Property>
      <Property name="month" type="integer">
        O número do mês (1-12).
      </Property>
      <Property name="month_name" type="string">
        O nome do mês.
      </Property>
      <Property name="collection_reception" type="float">
        Média de dias desde a colheita da amostra até à receção no laboratório.
      </Property>
      <Property name="reception_registration" type="float">
        Média de dias desde a receção no laboratório até ao registo da amostra.
      </Property>
      <Property name="registration_analysis" type="float">
        Média de dias desde o registo da amostra até à análise.
      </Property>
      <Property name="analysis_validation" type="float">
        Média de dias desde a análise até à validação do resultado.
      </Property>
    </Properties>
  </Col>
