# HIV Doença Avançada

Os endpoints para análise de testes de Doença Avançada por HIV estão actualmente em desenvolvimento. Este módulo abrangerá diagnósticos para pacientes com doença avançada por HIV. {{ className: 'lead' }}

<Note>
  Esta secção estará disponível em breve. Os seguintes tipos de teste serão documentados assim que os endpoints da API forem implementados.
</Note>

## Contagem de CD4

Teste de contagem de células CD4 para monitorização do estado imunitário em pacientes com HIV. As contagens de CD4 são fundamentais para identificar pacientes com doença avançada por HIV (contagem de CD4 inferior a 200 células/mm³) e orientar decisões de tratamento.

## CrAg (Antigénio Criptocócico)

Teste de antigénio criptocócico para diagnóstico de meningite criptocócica em pacientes com doença avançada por HIV. O rastreio de CrAg é recomendado para todos os pacientes seropositivos com contagens de CD4 inferiores a 200 células/mm³.

## TB-LAM (Ensaio de Fluxo Lateral Urinário LAM)

Ensaio de lipoarabinomanano (LAM) urinário de fluxo lateral para diagnóstico rápido de tuberculose em pacientes seropositivos com imunossupressão avançada. O teste TB-LAM permite o diagnóstico de TB no ponto de atendimento em contextos onde os diagnósticos baseados em expectoração são difíceis.
