# Início Rápido

Este guia vai ajudá-lo a começar a utilizar a API OpenLDR Analytics. Você aprenderá como autenticar, fazer sua primeira requisição e entender os parâmetros de consulta comuns. {{ className: 'lead' }}

## Autenticação {{ tag: 'POST', label: '/auth/login' }}

<Row>
  <Col>
    Todos os endpoints da API requerem autenticação via token JWT Bearer. Para obter um token, envie uma requisição `POST` para o endpoint `/auth/login` com as suas credenciais.

    A resposta incluirá um `access_token` que deve ser incluído no cabeçalho `Authorization` de todas as requisições subsequentes.

    <Properties>
      <Property name="user_name" type="string">
        O seu nome de utilizador da conta OpenLDR.
      </Property>
      <Property name="password" type="string">
        A sua palavra-passe da conta OpenLDR.
      </Property>
    </Properties>
  </Col>
  <Col sticky>
    <CodeGroup title="Requisição" tag="POST" label="/auth/login">
    ```bash {{ title: 'cURL' }}
    curl -X POST https://api.openldr.org.mz/auth/login \
      -H "Content-Type: application/json" \
      -d '{
        "user_name": "your_username",
        "password": "your_password"
      }'
    ```

    ```python {{ title: 'Python' }}
    import requests

    response = requests.post(
        "https://api.openldr.org.mz/auth/login",
        json={
            "user_name": "your_username",
            "password": "your_password"
        }
    )

    token = response.json()["access_token"]
    ```

    ```javascript {{ title: 'JavaScript' }}
    const response = await fetch('https://api.openldr.org.mz/auth/login', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        user_name: 'your_username',
        password: 'your_password',
      }),
    })

    const { access_token } = await response.json()
    ```
    </CodeGroup>

```json {{ title: 'Resposta' }}
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```
  </Col>
</Row>

## Fazendo sua primeira requisição {{ tag: 'GET', label: '/hiv/vl/laboratories/tested_samples/' }}

<Row>
  <Col>
    Depois de obter o seu token de acesso, pode fazer requisições autenticadas a qualquer endpoint da API. Vamos começar por obter dados de amostras testadas de Carga Viral de HIV.

    Inclua o token no cabeçalho `Authorization` como um token Bearer. A API retornará dados em formato JSON que pode utilizar nas suas aplicações.
  </Col>
  <Col sticky>
    <CodeGroup title="Requisição" tag="GET" label="/hiv/vl/laboratories/tested_samples/">
    ```bash {{ title: 'cURL' }}
    curl https://api.openldr.org.mz/hiv/vl/laboratories/tested_samples/ \
      -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
    ```

    ```python {{ title: 'Python' }}
    import requests

    response = requests.get(
        "https://api.openldr.org.mz/hiv/vl/laboratories/tested_samples/",
        headers={
            "Authorization": f"Bearer {token}"
        }
    )

    data = response.json()
    ```

    ```javascript {{ title: 'JavaScript' }}
    const response = await fetch(
      'https://api.openldr.org.mz/hiv/vl/laboratories/tested_samples/',
      {
        headers: {
          Authorization: `Bearer ${access_token}`,
        },
      },
    )

    const data = await response.json()
    ```

## Parâmetros comuns {{ tag: 'ALL', label: 'Query Parameters' }}

<Row>
  <Col>
    A maioria dos endpoints da API aceita um conjunto de parâmetros de consulta comuns para filtragem e agregação de dados. Estes parâmetros permitem restringir os resultados por intervalo de datas, localização geográfica e nível de detalhe.

    <Properties>
      <Property name="interval_dates" type="JSON array">
        Filtro de intervalo de datas como um array JSON com duas datas no formato `YYYY-MM-DD`: `["2025-01-01","2025-12-31"]`. Por padrão, retorna os últimos 12 meses caso não seja fornecido.
      </Property>
      <Property name="province" type="string">
        Filtrar por nome da província. Suporta seleção múltipla passando o parâmetro várias vezes.
      </Property>
      <Property name="district" type="string">
        Filtrar por nome do distrito. Suporta seleção múltipla passando o parâmetro várias vezes.
      </Property>
      <Property name="health_facility" type="string">
        Filtrar por nome de uma unidade sanitária específica.
      </Property>
      <Property name="facility_type" type="string">
        Nível de agrupamento para resultados agregados. Valores aceites: `"province"`, `"district"`, `"health_facility"`.
      </Property>
      <Property name="disaggregation" type="string">
        Activar ou desactivar a desagregação de dados. Valores aceites: `"True"` ou `"False"`.
      </Property>
    </Properties>
  </Col>
  <Col sticky>
    <CodeGroup title="Requisição com parâmetros" tag="GET" label="/hiv/vl/laboratories/tested_samples/">
    ```bash {{ title: 'cURL' }}
    curl -G https://api.openldr.org.mz/hiv/vl/laboratories/tested_samples/ \
      -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
      --data-urlencode 'interval_dates=["2025-01-01","2025-12-31"]' \
      --data-urlencode "province=Maputo Cidade" \
      --data-urlencode "province=Gaza" \
      --data-urlencode "facility_type=district" \
      --data-urlencode "disaggregation=True"
    ```
    </CodeGroup>
  </Col>
</Row>

## Tratamento de erros

<Note>
  Se receber uma resposta `401 Unauthorized`, o seu token JWT pode ter expirado. Solicite um novo token chamando o endpoint `/auth/login` novamente.
</Note>

A API utiliza códigos de status HTTP padrão para indicar o sucesso ou falha de uma requisição.

| Código de Status | Descrição |
|------------------|-----------|
| `200` | **Sucesso** — A requisição foi processada com sucesso. |
| `401` | **Não Autorizado** — O token JWT está ausente, inválido ou expirado. |
| `500` | **Erro do Servidor** — Ocorreu um erro inesperado no servidor. |

```json {{ title: 'Resposta de erro' }}
{
  "error": "Unauthorized",
  "message": "Missing or invalid authentication token.",
  "status_code": 401
}
```
