# TB GeneXpert - Summary

System-wide summary and dashboard endpoints for TB GeneXpert analytics. These endpoints provide aggregated indicators, positivity rates by month and laboratory, and sample type distribution across the entire GeneXpert testing network. {{ className: 'lead' }}

## Common parameters

<Row>
  <Col>
    Most summary endpoints accept a common set of query parameters for filtering data by date range, geographic location, facility attributes, and GeneXpert result type.

    <Properties>
      <Property name="interval_dates" type="JSON array">
        Date range filter as a JSON array with two dates in `YYYY-MM-DD` format: `["2025-01-01","2025-12-31"]`. Defaults to the last 12 months if not provided.
      </Property>
      <Property name="province" type="string">
        Filter by province name. Supports multi-select by passing the parameter multiple times.
      </Property>
      <Property name="district" type="string">
        Filter by district name. Supports multi-select by passing the parameter multiple times.
      </Property>
      <Property name="health_facility" type="string">
        Filter by a specific health facility name.
      </Property>
      <Property name="facility_type" type="string">
        Grouping level for aggregated results. Accepted values: `"province"`, `"district"`, `"health_facility"`.
      </Property>
      <Property name="disaggregation" type="string">
        Enable or disable data disaggregation. Accepted values: `"True"` or `"False"`.
      </Property>
      <Property name="genexpert_result_type" type="string">
        Filter by cartridge type. Accepted values: `"Ultra 6 Cores"`, `"XDR 10 Cores"`.
      </Property>
    </Properties>
  </Col>
  <Col sticky>
    <CodeGroup title="Request with parameters" tag="GET" label="/tb/gx/summary/summary_header_component/">
    ```bash {{ title: 'cURL' }}
    curl -G https://api.openldr.org.mz/tb/gx/summary/summary_header_component/ \
      -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
      --data-urlencode 'interval_dates=["2025-01-01","2025-12-31"]' \
      --data-urlencode "province=Maputo Cidade" \
      --data-urlencode "district=KaMpfumo" \
      --data-urlencode "facility_type=district" \
      --data-urlencode "disaggregation=True" \
      --data-urlencode "genexpert_result_type=Ultra 6 Cores"
    ```
    </CodeGroup>
  </Col>
</Row>

## Summary header component {{ tag: 'GET', label: '/tb/gx/summary/summary_header_component/' }}

<Row>
  <Col>
    Returns a single object with the main GeneXpert dashboard indicators for the selected period. Includes totals for registered, analyzed, detected, and not detected samples for both Ultra and XDR result types, along with average turnaround time, error counts, and invalid sample counts.

    <Properties>
      <Property name="Ultra_Registered" type="integer">
        Total number of Ultra samples registered in the system.
      </Property>
      <Property name="Ultra_Analysed" type="integer">
        Total number of Ultra samples that have been analyzed.
      </Property>
      <Property name="Ultra_Detected" type="integer">
        Total number of Ultra samples with MTB detected result.
      </Property>
      <Property name="Ultra_Not_Detected" type="integer">
        Total number of Ultra samples with MTB not detected result.
      </Property>
      <Property name="XDR_Registered" type="integer">
        Total number of XDR samples registered in the system.
      </Property>
      <Property name="XDR_Analysed" type="integer">
        Total number of XDR samples that have been analyzed.
      </Property>
      <Property name="XDR_Detected" type="integer">
        Total number of XDR samples with resistance detected.
      </Property>
      <Property name="XDR_Not_Detected" type="integer">
        Total number of XDR samples with no resistance detected.
      </Property>
      <Property name="AVG_TRL_Days" type="float">
        Average total turnaround time in days across all samples.
      </Property>
      <Property name="Errors" type="integer">
        Total number of samples that resulted in system errors.
      </Property>
      <Property name="Invalid" type="integer">
        Total number of samples with invalid results.
      </Property>
