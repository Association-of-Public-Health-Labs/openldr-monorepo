# TB GeneXpert - Patients

Patient-level search endpoints for TB GeneXpert results. These endpoints allow searching for individual patient records by name, health facility, sample type, or result type. All responses are paginated and include detailed patient demographics, facility information, specimen data, and full GeneXpert results including drug resistance markers. {{ className: 'lead' }}

## Common parameters

<Row>
  <Col>
    All patient search endpoints accept the following query parameters for filtering and pagination.

    <Properties>
      <Property name="interval_dates" type="JSON array">
        Date range filter as a JSON array with two dates in `YYYY-MM-DD` format: `["2025-01-01","2025-12-31"]`. Defaults to the last 12 months if not provided.
      </Property>
      <Property name="province" type="string">
        Filter by province name. Supports multi-select.
      </Property>
      <Property name="district" type="string">
        Filter by district name. Supports multi-select.
      </Property>
      <Property name="genexpert_result_type" type="string">
        Filter by cartridge type: `"Ultra 6 Cores"` or `"XDR 10 Cores"`.
      </Property>
      <Property name="page" type="integer">
        Page number for pagination. Defaults to `1`.
      </Property>
      <Property name="per_page" type="integer">
        Number of results per page. Defaults to `20`.
      </Property>
    </Properties>
  </Col>
  <Col sticky>
    <CodeGroup title="Request with parameters" tag="GET" label="/tb/gx/patients/by_name/">
    ```bash {{ title: 'cURL' }}
    curl -G https://api.openldr.org.mz/tb/gx/patients/by_name/ \
      -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
      --data-urlencode 'interval_dates=["2025-01-01","2025-12-31"]' \
      --data-urlencode "first_name=Maria" \
      --data-urlencode "surname=Silva" \
      --data-urlencode "genexpert_result_type=Ultra 6 Cores" \
      --data-urlencode "page=1" \
      --data-urlencode "per_page=20"
    ```
    </CodeGroup>
  </Col>
</Row>

## Search by name {{ tag: 'GET', label: '/tb/gx/patients/by_name/' }}

<Row>
  <Col>
    Search for patient GeneXpert results by first name and/or surname. Returns paginated results with full patient details, facility information, specimen data, and test results including drug resistance markers.

    <Properties>
      <Property name="first_name" type="string">
        Patient first name to search for. Partial matching supported.
      </Property>
      <Property name="surname" type="string">
        Patient surname to search for. Partial matching supported.
      </Property>
    </Properties>

    <span className="block mt-4 font-medium">Response fields:</span>

    <Properties>
      <Property name="status" type="string">
        Request status (`"success"` or `"error"`).
      </Property>
      <Property name="page" type="integer">
        Current page number.
      </Property>
      <Property name="per_page" type="integer">
        Number of results per page.
      </Property>
      <Property name="total_count" type="integer">
        Total number of matching records.
      </Property>
      <Property name="total_pages" type="integer">
        Total number of pages available.
      </Property>
      <Property name="data" type="array">
        Array of patient result objects containing: `RequestID`, `First_Name`, `Surname`, `Age`, `Sex`, `Requesting_Facility`, `Testing_Facility`, `Province`, `District`, `Final_Result` (MTB Detected/Not Detected), `MTB_Trace`, `Rifampicin_Resistance`, `Isoniazid_Resistance`, `Fluoroquinolone_Resistance`, `Sample_Type`, `Collection_Date`, `Registration_Date`, `Analysis_Date`, `Validation_Date`.
      </Property>
    </Properties>
  </Col>
  <Col sticky>
    <CodeGroup title="Request" tag="GET" label="/tb/gx/patients/by_name/">
