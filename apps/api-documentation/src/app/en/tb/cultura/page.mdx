## Culture Testing

Mycobacterial culture testing using liquid (MGIT) and solid (Lowenstein-Jensen) media for definitive TB diagnosis. Culture remains the gold standard for TB diagnosis and is essential for drug susceptibility testing.

## Drug Sensitivity Testing

First-line and second-line drug susceptibility testing (DST) to guide treatment of drug-resistant TB. Includes testing for isoniazid, rifampicin, ethambutol, pyrazinamide, fluoroquinolones, and injectable agents.
